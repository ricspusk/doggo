# Doggo — Getting Started with Websites

A tiny starter website for someone who has **never built one before**.
It's just three files, and it already works.

## The files

| File         | What it is                                                    |
| ------------ | ------------------------------------------------------------- |
| `index.html` | The **structure** — the words, headings, and buttons.         |
| `style.css`  | The **look** — colors, fonts, spacing.                        |
| `README.md`  | This guide.                                                   |

Every website in the world, no matter how fancy, is built on these same
foundations: HTML (structure), CSS (style), and JavaScript (interactivity).

## See it right now

You don't need any special tools to view it. Just **double-click `index.html`**
and it opens in your web browser. That's it — you're looking at a real web page
running on your own computer.

Now open `index.html` and `style.css` in a text editor, change some text or a
color, **save**, and **refresh the browser**. That loop — edit, save, refresh —
is 90% of web development.

## The big picture: how a website gets on the internet

Right now this site only exists on your computer. To put it online so anyone can
visit, you need two things:

1. **Hosting** — a computer that's always on, serving your files to visitors.
   You don't need to buy or run a physical server. For a simple site like this,
   these are **free** and beginner-friendly:
   - **GitHub Pages** — free, and works directly from a repo like this one.
   - **Netlify** or **Cloudflare Pages** — free, drag-and-drop your folder.

2. **A domain name** — the address people type, like `mydoggo.com`.
   You *rent* this (usually $10–15/year) from a **registrar** such as
   Namecheap, Cloudflare, or Porkbun. A domain is optional at first — the free
   hosts above give you a free address like `yourname.github.io` to start.

You do **not** need to buy a "webserver" — that's the old, expensive way.
Modern free hosting handles all of it.

## A suggested learning path

1. **Edit this site** until you're comfortable changing text, colors, and layout.
2. **Learn the basics properly** — [MDN's "Getting started"](https://developer.mozilla.org/en-US/docs/Learn)
   and [freeCodeCamp](https://www.freecodecamp.org/) are the two best free resources.
3. **Put it online for free** with GitHub Pages (ask me — I can set this up for you).
4. **Buy a domain** only once you have something you want to share.
