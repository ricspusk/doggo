# Emporio Animale

A premium, monochrome concept storefront for **feline luxury accessories** —
collars, marble bowls, cashmere beds. Editorial art direction inspired by
high-fashion houses: absolute black-and-white contrast, generous space, thin
tracked typography, and a minimalist cat emblem.

> **Emporio Animale is an original, fictional brand.** It uses no third-party
> logos, trademarks, or brand assets — only a shared design *language*.

## The files

| File         | What it is                                                        |
| ------------ | ----------------------------------------------------------------- |
| `index.html` | The page structure and content (products, sections, cat emblem).  |
| `style.css`  | The full visual design — palette, typography, layout, motion.     |
| `.nojekyll`  | Tells GitHub Pages to serve the files exactly as written.         |

## See it locally

Double-click `index.html` to open it in your browser. Edit the text or prices in
`index.html`, or the colors in `style.css`, then save and refresh.

## Design notes

- **Palette** — pure black `#0a0a0a` and white `#ffffff`, with one chosen warm
  grey `#6f6c68` for secondary text. Fully theme-aware (light & dark).
- **Type** — a light, wide-tracked sans for the wordmark and headings, paired
  with an italic serif for editorial statements.
- **Imagery** — placeholder cat emblems drawn in SVG stand in for photography.
  Swap these for real product photos when you have them.

## Making it a real shop

This is the *storefront design*. To actually sell, the usual next steps are:
adding real product photos, then connecting a checkout (Shopify, Stripe, or a
hosted store) so the "Aggiungi alla borsa" buttons take payments. Ask and I'll
walk you through it.
